# Halluguard

Halluguard is a security-focused demo project designed as a foundation for building safety and monitoring solutions.

## Demo Features

- Clean web interface
- Security dashboard foundation
- Modular frontend structure
- Easy local deployment

## Project Structure

```
Halluguard/
├── index.html       # Main demo page
├── style.css        # UI styling
├── script.js        # Demo interactions
├── README.md        # Documentation
└── .gitignore       # Git configuration
```

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Explore the demo
